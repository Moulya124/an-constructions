# A N Constructions — Website

A modern, responsive multi-page website for **A N Constructions**, focused on civil engineering, construction, contracting, and project enquiries.

## Live Website

https://an-constructions.onrender.com

## Features

- Responsive construction company website
- Modern and elegant UI
- Home page
- Services page
- Projects portfolio
- About page
- Contact page
- Responsive navigation
- Construction project images
- Contact form
- Direct email enquiries using FormSubmit
- No custom backend required
